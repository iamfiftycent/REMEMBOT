# REMEMBOT

Telegram-бот для создания напоминаний на определенную дату и время.

## Возможности

- Создание напоминаний
- Проверка формата даты и времени
- Отправка уведомлений пользователю
- Отмена создания напоминания
- Многопоточность для проверки напоминаний

---

## Используемые технологии

- Python 3
- pyTelegramBotAPI (`telebot`)
- threading
- datetime

---

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/USERNAME/REMEMBOT.git
cd REMEMBOT
```

### 2. Создать виртуальное окружение

```bash
python -m venv venv
```

### 3. Активировать окружение

#### macOS / Linux

```bash
source venv/bin/activate
```

#### Windows

```bash
venv\Scripts\activate
```

### 4. Установить зависимости

```bash
pip install -r requirements.txt
```

---

## Настройка

Создай файл:

```text
bot/config.py
```

И добавь туда токен бота:

```python
TOKEN = 'ВАШ_ТОКЕН'
```

Получить токен можно у Telegram-бота
BotFather.

---

## Запуск

```bash
python main.py
```

## Использование

### Команды

| Команда | Описание |
|---|---|
| `/start` | Запуск бота |
| `/help` | Список команд |
| `Напомни` | Создать напоминание |
| `/back` | Отмена создания напоминания |

---

## Формат даты и времени

Дата:

```text
ДД.ММ.ГГГГ
```

Пример:

```text
19.05.2026
```

Время:

```text
ЧЧ:ММ
```

Пример:

```text
14:30
```
